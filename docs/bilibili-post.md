## 简介

```
给 DeepSeek Harness 写了个小插件「鱼的耳机」：
让聊天区右边那列轮次轨道，跟着电脑正在播放的声音一起起伏。

· 支持抓整个输出设备，也可以只抓某个应用（QQ音乐、Chrome、游戏都行）
· 两种形状：海浪（流动）/ 中间高两边低（静止山形）
· 彩虹流光、单色、外圈泛光、低谷/高峰幅度、最长长度，全部能调
· 只算音量和频谱，不录音、不上传

安装：DSH 插件页点「添加插件」，输入 dsh-whale-pulse 回车，
或者粘贴 GitHub 地址重启即可。

开源地址：https://github.com/XiaTian-606/dsh-whale-pulse
npm 地址：https://www.npmjs.com/package/dsh-whale-pulse

视频里的表情包来自 fisharchive.cc 同人整理站
（CC BY-NC-SA 4.0，非商业使用）。
角色形象原作：上善无形；DeepSeek 元素二次设计：ZipZipPipe；表情整理：EDMOK。

求个一键三连，让更多鱼友看到～
```
