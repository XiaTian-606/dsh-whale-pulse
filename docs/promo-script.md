# 鱼的耳机 · B 站宣传视频分镜脚本

> 时长目标：60~90 秒。节奏：先抛效果，再讲痛点，再演示，最后安装与三连。
> 录屏建议：1920×1080、60fps，DSH 窗口全屏，系统音量调大一点让轨道律动明显。

## 视频信息

**标题**

```
给 DeepSeek Harness 装了个"鱼的耳机"，聊天轨道会跟着音乐跳！
```

**封面文案**（大字）：`鱼的耳机`，小字：`让 DSH 轨道跟着音乐律动`

**简介**

```
给 DeepSeek Harness 写了个小插件「鱼的耳机」：
让聊天区右边那列轮次轨道，跟着电脑正在播放的声音一起起伏。

· 支持抓整个输出设备，也可以只抓某个应用（QQ音乐、Chrome、游戏都行）
· 两种形状：海浪 / 中间高两边低
· 彩虹流光、单色、外放光晕、低谷/高峰幅度都能自己调
· 只算音量和频谱，不录音、不上传

开源地址：https://github.com/XiaTian-606/dsh-whale-pulse
DSH 插件里填这个 GitHub 地址就能装。

求个一键三连，让更多鱼友看到～
```

## 录屏小贴士

1. **先放一首节奏明显的歌**（鼓点清晰），轨道律动最直观；
2. 录屏时把「浮动幅度」调到 200%~300%，大浪效果更明显；
3. 设置页慢慢滚，**别手抖**，观众要看清每一项；
4. 安装那段可以**加速播放**（后期 2x），太长容易掉人；
5. 结尾三连卡要留 **2~3 秒**，方便观众看。
